# Security policy

SPSP is pre-release. Do not use it with a save that cannot be replaced from a known-good backup.
SPSP must not edit NMS save files; report any behavior suggesting otherwise as a security issue.

Please report vulnerabilities privately through GitHub's **Report a vulnerability** feature. Include
the affected release or commit, NMS build, reproduction steps, expected impact, and a minimal test
case where possible. Do not publish save files, credentials, personal account details, proprietary
game assets, or player/ship identifiers in the report.

Dependency and workflow changes are reviewed through pull requests. Dependabot security updates
create pull requests; no automation merges them.
